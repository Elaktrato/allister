# TV Plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the opt-in TV plugin (one Show kind, TVmaze + optional TMDB, Yamtrack TV CSV import, calendar) plus the `Airing.Season` and `ResetOnPrimary` core changes.

**Architecture:** One `show` kind with season/episode/position progress. TVmaze is the free source and the only scheduler; TMDB is declared only with `TMDB_API_KEY`. A shared raw Yamtrack CSV parser feeds an anime wrapper and a TV aggregator. The calendar stores a season with each airing, and `+1` clears duration tracks marked reset-on-primary.

**Tech Stack:** Go 1.27.3 (Docker), SQLite, htmx, Tailwind, existing plugin/library/importer/web layers, shared `anilist` text helper and `jsonexport`.

**Spec:** `docs/superpowers/specs/2026-11-11-tv-plugin-design.md`

## Global Constraints

- No new Go dependencies; all tests via `scripts/go.sh`; full suite, vet, fmt before each commit.
- Plugin contract data only; no plugin HTML/JS; core guard; no hard-coded colours.
- Next free migration is **00016**; never edit applied migrations.
- TVmaze about 20 requests/10 seconds: declare 30/minute and rely on core pacing.
- TMDB key only in `TMDB_API_KEY`; never log it. TMDB source is not declared without a key.
- No scraping; MyDramaList is issue #2; Trakt/TV Time are issue #3.
- README ≤150 lines; docs tests green.
- Preview only on port 18083 / `allister-preview`; owner's ports untouched; owner pushes.

## Review Focus

- Yamtrack episode rows with blank status: presence is watched, not status; a season/TV `progress` supplies counts.
- A titled TV row with no TMDB/TVDB id becomes manual; only a title-less TV row is skipped.
- `+1` advances the episode and resets the active `position` track; it must not reset other tracks.
- Two TV seasons may have the same episode number; calendar rows/UIDs must not collide.
- A missing/invalid TMDB key must not be logged and must not remove TVmaze; a 401/403 is bad input, not a retry loop.
